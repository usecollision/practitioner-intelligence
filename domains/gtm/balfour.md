## Beliefs
- Growth is a system, not a tactic; stage determines the model (FRAMEWORK).
- Loops > funnels when there's a natural mechanic; AARRR is linear and misses compounding.
- Growth teams must ship product changes (activation, retention), not just run campaigns (HEURISTIC).
## Principles
- Model must match stage: pre-PMF = learn; post-PMF = compound (HEURISTIC, T2).
- Every loop: Trigger → Action → Output → Input (back to Trigger). If output doesn't feed a new cycle, it's a funnel (FRAMEWORK, T1).
- Retention is the first growth lever; acquisition scales what retention keeps (HEURISTIC, T2).
## Frameworks
- Growth Loops (2018 essay): viral/content/paid/sales loops; each has a cycle time and per-stage conversion (FRAMEWORK, T1).
- Connected Systems framework: loops + channels + strategy must align (FRAMEWORK, T2).
## Decision rules
- IF no PMF THEN don't build a growth team/engine — fix product (T2).
- IF product has no sharing/network mechanic THEN don't force viral loops; use paid or content loops (T1).
- IF loop conversion < 1.0 without paid input THEN the loop is dead; fix or kill (HEURISTIC, T2).
- IF retention curve is flat THEN fix activation/retention before scaling acquisition (T2).
## Failure modes
- Hiring growth team with no roadmap access/decision rights → campaigns without product change (T2).
- Forcing virality without mechanic → viral coefficient <1 = paying for every user (FRAMEWORK).
- Scaling a funnel (not loop) and wondering why growth doesn't compound (T2).
## Conditions
- B2B/B2C SaaS with instrumentation; post-PMF; product team that can ship (T2).
