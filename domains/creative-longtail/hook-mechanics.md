- ## Beliefs — The hook is the single highest-impact element of any ad: "failed ads die at the hook, not the offer" (Hormozi). The window is 0–3 seconds (0.3–0.8s scroll decision, 50–70% loss in first 1–2s — social.md/short-form-hook-retention). The hook is the shortest part of the ad and the only part that decides whether the rest gets seen; spend the pre-work there.
- ## Frameworks
  - **Hook-Meat-CTA** (Hormozi): hook names the buyer's pain in 3–4 words; meat = value-dense middle with specificity in the buyer's own words; CTA = one clear action. Diagnose which of the three parts is failing before rewriting the whole ad.
  - **"Write fifty hooks before you write one ad"** (Hormozi): pre-search over editing; pick the winners from volume.
  - **H-A-P** (vexub): Hook word/pattern interrupt → Audience call-out → Promise. Stack 2+ triggers per opener; mirror the spoken hook in the on-screen caption (audio+visual compounding).
  - **Attention Grab** (Hormozi-inspired): wake-up-call hook → pain callout → reframe → emotional contrast (inaction vs action) → challenge CTA.
  - **Hook splicing** (Hormozi): isolate the first 3s of top 5–10% of ads; graft onto 100+ other ads → 10–50x creative per proven hook.
- ## Heuristics
  - Thumb-stop 30–50% = good on Meta (ORCA, T3). Hook 0–3s, context 3–5s ("if you run an ecommerce store…"), then value (ORCA hook-to-message sequence).
  - IF biggest retention drop at 1s THEN stronger pattern interrupt; IF at 3s THEN the promise is too weak (vexub).
  - Specificity beats cleverness; pain articulation beats promise articulation (Hormozi).
- ## Decision rules
  - IF opening an ad THEN name the buyer's pain in ≤4 words, never lead with features (Hormozi — HEURISTIC, T2).
  - IF generating hooks THEN produce 50 options per angle, ship the top 3 (Hormozi — HEURISTIC, T2).
  - IF short-form video THEN layer visual+audio+text and caption-mirror the spoken hook (vexub/social.md — HEURISTIC, T3).
  - IF retention graph shows the drop at 1s THEN rebuild the pattern interrupt; at 3s THEN strengthen the promise (vexub — HEURISTIC, T3).
  - IF you have proven winners THEN reskin/splice them before inventing new creative (Hormozi — TACTIC, T2/T3).
  - IF audience is cold/new THEN problem-agitating, conversational hooks; IF warm/retargeting THEN offer/close hooks (Denney + Schwartz via messaging.md — HEURISTIC, T2).
- ## Metrics — thumb-stop/3s watch rate (benchmark 30–50% Meta), 15s watch rate, hook-level CTR/CPA, retention drop-points.
- ## Failure modes — feature-list openings ("almost nobody scrolls past a feature list" — Hormozi); polite intros/logo splashes in the first 3s; no curiosity/promise; generic hooks; one message for all awareness levels (Schwartz).
- ## Conditions — direct-response paid social and short-form video; works for organic content with adapted platform norms (LinkedIn first-line ≠ TikTok 1s hook).
- ## Limitations — Hormozi's figures self-reported (T3); platform windows shift; H-A-P/benchmarks from a single content-education source (T3).
