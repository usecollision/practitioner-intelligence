## Beliefs
- Dashboards exist for decisions, not data display; most dashboards "puke data" (FRAMEWORK, T1).
- "Focus only on KPIs, eliminate metrics" — metrics not tied to business success get killed (HEURISTIC, T1).
## Principles
- ~6 KPIs for CEO, ~6 for CMO, each with target + benchmark (HEURISTIC, T1).
- Only KPIs with pre-assigned targets belong on a dashboard (T1).
- Focus on outliers: KPIs 3 standard deviations from the mean get attention; normal is ignored (HEURISTIC, T1).
- Watch for sandbagged targets; sanity-check vs industry benchmarks (T1).
## Frameworks
- KPI hierarchy: CEO KPIs → CMO KPIs → micro-diagnostics (analysis views, not dashboards) (FRAMEWORK, T1).
- Dashboard columns: KPI, Target, Benchmark (TACTIC, T1).
## Decision rules
- IF a dashboard metric has no target THEN remove it (T1).
- IF KPI deviates >3σ THEN escalate with hypothesis (T1).
- IF targets look low THEN benchmark externally before accepting (T1).
- IF execs see >10 KPIs THEN re-hierarchy to ~6 (T1).
## Failure modes
- Data-puking dashboards nobody reads (T1).
- Metric soup with no decisions attached (T1).
- Sandbagging targets (T1).
## Conditions
- Orgs with exec reporting cadence; fails where no targets exist (then set targets first) (T1).
