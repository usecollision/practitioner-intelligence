- ## Beliefs — PR is an integrated operating system (PESO), not a function that writes releases. Measurement must tie to business outcomes (revenue, reputation, recruiting, risk), not outputs (clips/AVEs). In an AI-first world, earned media is the most-cited source: >95% of links AI engines surface come from earned, shared, and organic owned content (as reported by Spin Sucks).
- ## Principles — Owned anchors authority; shared distributes + stress-tests + listens; earned validates (third-party credibility); paid amplifies what's already working. Design handoffs before the calendar; start with business goals, not media tactics. "Your measurement problem usually isn't a measurement problem" — you can't gauge a system that isn't running as a system.
- ## Frameworks — PESO Model (2014; now "MarComm Operating System"); IMC philosophy vs PESO operationalization; handoff design.
- ## Processes — business goals → map to PESO mix → create owned foundation → distribute via shared → earn coverage → amplify winners with paid → measure with tagging/correlation/journey mapping.
- ## Heuristics — if paid is amplifying content nobody engaged with organically, the funnel is inverted; if owned doesn't feed earned, PR is disconnected from content.
- ## Metrics — visibility in AI/search, engagement depth, trust signals, pipeline/reputation outcomes; correlation models, campaign tagging, journey mapping.
- ## Decision rules
  - IF no owned content foundation THEN build it before investing in paid amplification. (FRAMEWORK, T2)
  - IF goal = AI-search visibility THEN prioritize earned + shared + owned organic content (95%+ of AI citations). (EMPIRICAL as reported, T2)
  - IF a tactic's output can't be tagged to a business outcome THEN don't run it as a standalone. (FRAMEWORK, T2)
  - IF budget is tight THEN run owned+shared first; add paid only to amplify proven winners. (FRAMEWORK, T2)
- ## Failure modes — measuring outputs not outcomes; channel silos (PR without content, content without distribution); paid-first without organic validation.
- ## Conditions — works for orgs with content teams and multi-channel capacity; a solo founder can start with owned+shared only.
- ## Limitations — T2: her "6x performance" and "95% AI links" claims come from her own marketing; single-source framework (though widely adopted).
