## Beliefs
- AI search optimization is a distinct execution workflow, not isolated content tweaks: prompts → measurement → gap analysis → fixes → validation. ("AI Search Optimization Checklist," updated May 2026) — FRAMEWORK
- "The first mistake I see some still make is to start 'optimizing for AI search' without defining what that means." AI visibility is not one generic outcome: a brand can be visible for informational prompts, absent from commercial comparison prompts, misrepresented in evaluation prompts, and cited only via third-party sites. — OPINION/HEURISTIC
- "Optimization should start from observed presence, not from a reflex to create more content." — PRINCIPLE
- AI search platforms process queries, evaluate content, and weigh authority signals differently from traditional search — a fresh optimization mindset is required (AirOps webinar, Jun 2026). — OPINION
- Measurement must avoid overclaiming: "How will we measure progress without overclaiming impact?" is a required checklist question.

## Principles
- Build the prompt library from real demand language: non-brand demand data, sales and support transcripts, review and community language, AI research tool samples — NOT keyword tools stretched into questions.
- Optimize from observed presence: measure before creating content.
- Track by platform, prompt type, market, product line, and journey stage; analyze at topic level, not individual prompt level.
- Treat individual prompt outputs as samples, not fixed rankings — AI answers vary across runs.
- Technical crawlability is a prerequisite: minimize reliance on client-side JavaScript so AI bots can read pages.
- Structure content as topic clusters with semantically tight, self-contained chunks.

## Frameworks
- 10-step AI search optimization checklist (audience/prompt research → technical crawlability → topic clusters + chunking → citation strategy → measurement/validation).
- Five Presence KPIs (her named set): presence by platform, prompt type, market, product line, journey stage — analyzed at topic level; presence beyond binary "mentioned/not mentioned" (a brand can appear but not be recommended, or be cited only via third parties).
- LearningAIsearch.com: free education hub for GEO/AEO/LLMO fundamentals, technical config, content optimization, measurement, tools.

## Processes
- (1) Define which AI search journeys to influence; (2) measure current presence/citation/recommendation state per platform; (3) identify which owned pages and third-party sources shape the answers; (4) fix gaps; (5) validate with before/after measurement without overclaiming.

## Heuristics
- AI search queries are longer, conversational, and more task-focused than traditional queries — optimize for journeys, not keywords.
- If you can't measure it per platform, you can't claim progress.
- Presence without recommendation is a partial failure; citation via third parties only is a partial failure.

## Tactics
- Create prompt libraries from sales/support transcripts and review language.
- Server-side render critical content; allow AI crawlers (GPTBot, PerplexityBot, ClaudeBot, Google-Extended).
- Organize content into topic clusters; write self-contained chunks that answer one question fully.
- Audit competitor/third-party sources that shape answers in your vertical.

## Tools
- LearningAIsearch.com; standard SEO stack (crawl tools, GSC); AI engines for answer sampling; prompt libraries.

## Inputs
- Non-brand demand data, sales/support transcripts, review/community language, AI answer samples, per-platform presence data.

## Outputs
- AI search optimization checklists, audits, training, LearningAIsearch.com guides.

## Metrics
- Five Presence KPIs per platform/prompt type/market/product line/journey stage; before/after citation presence; topic-level presence.

## Decision rules
- If you can't name which journeys matter → build the prompt library from transcripts/reviews first; do not start creating content.
- If presence is low across engines → fix technical crawlability and indexing before content investment.
- If visible but cited via third parties only → strengthen owned-page representation (entity clarity, answer structure).
- If answers vary run-to-run → aggregate samples per topic before deciding anything.

## Failure modes
- Keyword-tool-only prompt libraries (misses conversational/task queries).
- Treating one AI answer as ground truth (sampling error).
- Creating content before measuring presence (reflex optimization).
- Overclaiming impact without per-platform baselines.

## Contrarian beliefs
- GEO is not "just SEO" (contra Ryan Law): she treats AI search as needing its own optimization mindset and workflow — while agreeing the fundamentals (crawlability, relevance) carry over.

## Conditions
- Works for brands with multi-stage buyer journeys and enough demand language data (transcripts/reviews); scales to enterprises and competitive markets.
- Heavy on process discipline; teams without measurement capacity get limited value.
