## Beliefs
- Topical Authority is a semantic SEO methodology: rank by processing connected topics and entailed search queries with accurate, unique, expert information — a methodology "to improve the rankings of a website without backlinks" (FRAMEWORK — he coined/formalized the concept; verify claims: largely self-published, tied to Google patents interpretation).
- Entities are language-agnostic; an entity-based approach lets one topical structure work across languages (FRAMEWORK/HYPOTHESIS).
- Google's passage indexing rewards coherent topical structure and punishes pages that dilute dominant intent across sections (HYPOTHESIS based on patents + observation).

## Frameworks
- **Topical Graph**: the cornerstones of a topic — the how/what/who/where questions and their answers, entities, and related concepts form a graph you should cover completely (FRAMEWORK).
- **Contextual/Conceptual Hierarchy**: the hierarchy between contextual web sections (e.g., flight-ticket search has sub-intents: holiday vs business) (FRAMEWORK).
- **Topical Map / Query-SERP mapping**: mapping SERPs to understand "topical borders" — whether a new page is warranted and how to build semantic URL + internal link structure (FRAMEWORK).
- **Semantic Content Network**: cover every relevant neural-net (sub-topic), context, and intent within a network of interlinked content with contextual anchor texts (FRAMEWORK).

## Processes
1. Build a topical graph for the target topic (entities, attributes, sub-topics, question-based cornerstones).
2. Map SERPs per query to define topical borders (should this be one page or several?).
3. Structure content around dominant intent per page (canonical intent); avoid diluting with off-intent sections.
4. Cover entities with accurate, unique, expert information; link contextually with descriptive anchors.
5. Balance PageRank internally toward the most authoritative source pages (FRAMEWORK).

## Heuristics
- If a page's initial section talks about something different from the main search intent, the page is weaker on user-satisfaction and relevance (HEURISTIC).
- Covering entities + attributes + sub-topics = expertise signal without backlinks (HEURISTIC).
- Passage ranking will "ignore" the rest of a page for queries that match only one passage — don't dilute pages with unrelated content (HEURISTIC).

## Tactics
- Use Google's NLP API for entity/attribute discovery (TACTIC).
- Contextual anchor texts and semantic internal linking across the cluster (TACTIC).
- Query-SERP mapping before deciding to open a new page (TACTIC).

## Metrics
- Organic clicks, keyword footprint breadth, entity coverage (his case studies cite traffic numbers).

## Decision rules
- Query belongs to the same neural-net/sub-topic as an existing page → strengthen that page, don't create a new one (DECISION RULE).
- Query requires a different context hierarchy (different sub-intent) → new page, linked contextually (DECISION RULE).
- No backlink capacity (new/small site, competitive niche) → build topical authority instead of chasing links (DECISION RULE — his stated method).

## Failure modes
- Covering a topic without entity depth — surface keyword-stuffed "coverage" that lacks the topical graph (implied).
- Diluting dominant intent on a page with mixed subtopics — passage ranking ignores the rest (warned).
- Treating topics as keyword lists rather than connected entity graphs (warned).

## Contrarian beliefs
- You can rank without backlinks via topical coverage — directly contradicts the link-heavy consensus (OPINION; other practitioners (Eli Schwartz, Paddy Moogan) would condition this on niche competitiveness).

## Conditions
- Works for informational/commercial-research content in niches where entity coverage is achievable; suits new sites that can't buy links; requires research discipline most teams lack.
- His case studies: content-heavy, competitive informational niches.

## Limitations
- Self-published methodology with patent-interpretation basis — causal claims (0→128k clicks) unverified by independent sources; very high effort per topic; weaker for transactional/local intent; some claims are more elaborate than evidence supports (T3-grade evidence).
