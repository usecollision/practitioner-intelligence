## Beliefs
- "What got us here, won't get us there": the pre-2012 link playbook (mass directories, article spinning/syndication, web 2.0 properties) is dead — Penguin ended the numbers game (OPINION/EMPIRICAL — he's the historian of this shift).
- Asking for every link is not sustainable: if links stop when outreach stops, the system isn't a system; and per-link ROI of bespoke asks doesn't scale (FRAMEWORK/OPINION).
- Content-led link building became the post-Penguin consensus — but saturation means it must keep evolving (OPINION).

## Frameworks
- **The Moz Guide to Link Building** (his canonical methodology): research → asset creation → outreach → measurement as a repeatable loop (FRAMEWORK — canonical artifact of the discipline).
- **Sustainable link acquisition test**: would links accrue without continuous bespoke asking? (FRAMEWORK/HEURISTIC).

## Processes
1. Identify link-worthy assets (data, tools, original research, resources).
2. Build the asset with the target audience in mind.
3. Outreach to relevant publishers with a specific, useful angle.
4. Measure and iterate; scale the parts that compound.

## Heuristics
- If a tactic needs 100% of links to be hand-asked, it's a job, not a strategy (HEURISTIC).
- Post-Penguin risk calculus: the downside (penalty/devaluation) must be priced into every tactic choice (HEURISTIC).

## Tactics
- Content marketing + digital PR as the core loop (TACTIC).
- Asset-first outreach (value before ask) (TACTIC).

## Tools
- Link research tools (Ahrefs-class), outreach tools (specifics UNKNOWN).

## Inputs
- Audience/target-site research, asset inventory, competitive link landscapes.

## Outputs
- Link building strategies/processes; the field's foundational guide.

## Metrics
- Referring domains, link quality distribution, link acquisition rate vs outreach volume.

## Decision rules
- Tactic carries penalty risk post-Penguin (mass directories, spun content, paid links) → exclude regardless of short-term ROI (DECISION RULE).
- Tactic requires hand-asking every link with no compounding → treat as non-scalable; invest in assets instead (DECISION RULE).
- Niche has linkable data/assets you can produce → content-led link building is the default (DECISION RULE).

## Failure modes
- The pre-2012 playbook (named dead: directory submissions, article spinning, web 2.0 links) (EMPIRICAL).
- Outreach-dependent link profiles that collapse when activity stops (warned).

## Contrarian beliefs
- Post-Penguin "safe" consensus itself needs continuous revision — what worked for the last ten years won't work for the next ten (OPINION — his 2022 Aira essay framing).

## Conditions
- Works for sites that can produce linkable assets (data, research, tools); B2B and media contexts; requires content production capacity.

## Limitations
- Content-led linking is slow and resource-heavy; doesn't fit local/niche businesses without asset capacity; his methodology predates AI-search-era link value shifts (partially legacy).
