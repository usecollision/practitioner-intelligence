# Panel — Pinterest Ads

## Experts found
- **Md Sharifuzzaman** (Pinterest Advertising Stuff / Decor Ads Pro; 343+ Pinterest projects since 2019) — furniture catalog case 39.94x ROAS over 22 months; detailed what-worked/what-didn't (T2; vendor but with concrete test data).
- **Vixen Digital** (ecom agency, Galvan London) — fashion bridal: 2.5x → 5x ROAS in 3 months via awareness→conversion→DPA funnel (T2).
- **Pinterest Business blog** (official) — shopping best practices with internal stats (T2, platform).
- **Riha Web Tech** — 3.8x average ROAS claim (T3); **Dataslayer** — earned impressions note (T3).

## Beliefs
- Pinterest = planning-intent, lower-funnel-ish catalog channel: users save ideas 30–90 days before purchase; intent quality higher than Meta cold (Sharifuzzaman; platform docs, CONSENSUS).
- **Catalog quality is the single biggest lever**: category-first titles (brand keyword in title = +28% ROAS, pattern keyword +22% — Pinterest internal), lifestyle hero images, feed hygiene (T2, platform EMPIRICAL).
- **Always-on beats bursts**: campaigns 6+ months ≈ +25% ROAS; <3 months = −5–16% vs average; pausing resets learning (Pinterest internal, EMPIRICAL, T2).
- **Auto-targeting beats manual overlays** on catalog campaigns: adding interest/keyword overlays dropped ROAS 39x→31x for 6 weeks in a direct test (Sharifuzzaman, EMPIRICAL, T2).
- Scale ≤15–20%/month; rapid budget increases reset optimization and cause temporary ROAS drops (Sharifuzzaman, HEURISTIC).
- Month 1–3 below benchmark is normal — algorithm builds conversion signal (Sharifuzzaman; aligns with platform docs, CONSENSUS).
- Measurement: CAPI + tag = 9% better CPA / 23.7% more attributed conversions vs tag-only (Pinterest internal); wide attribution gap between Pinterest and GA4 (Sharifuzzaman, EMPIRICAL).
- Structure: one dominant catalog campaign (~80% spend) + collections + small retargeting; fragmented micro-campaigns slow the algorithm (HEURISTIC).

## Failure modes
- Running Pinterest like Meta (interest-targeted static ads without catalog) — standard non-catalog ads "didn't work" in the flagship case.
- Pausing/rebuilding campaigns for sales events — destroys learning; rotate creative in instead.
- Overlaying manual targeting on auto-targeted catalog campaigns — bid inflation, no reach gain.
- Bad feed (brand-first titles, white-background shots for lifestyle categories) — the ROAS is lost before spend.
- Judging ROAS before 90 days; scaling >20%/mo.
- Price/image mismatch ad→product page→checkout kills post-click (Pinterest checklist #5).

## Decision rules
1. IF running shopping/catalog campaigns THEN keep them always-on year-round; never pause for seasonal events — rotate creative/promotions instead (Pinterest internal, EMPIRICAL, T2).
2. IF catalog underperforms THEN fix feed first (category-first titles, lifestyle images, price accuracy) before touching bids (Sharifuzzaman/Pinterest, EMPIRICAL, T2).
3. IF using catalog auto-targeting THEN do not add interest/keyword overlays (Sharifuzzaman, EMPIRICAL, T2).
4. IF scaling THEN cap increases at 15–20%/month and wait for ROAS re-stabilization (Sharifuzzaman, HEURISTIC, T2).
5. IF evaluating Pinterest THEN require 90-day window + CAPI tracking + compare against GA4/attribution gap, not dashboard ROAS alone (T2).
6. IF category is visual, high-AOV, planning-driven (furniture, decor, weddings, fashion) THEN Pinterest beats Meta/Google on CPA; IF low-visual B2B service THEN skip (Sharifuzzaman/Vixen, HEURISTIC, T2).
