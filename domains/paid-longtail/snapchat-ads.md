# Panel — Snapchat Ads

## Experts found
- **Common Thread Collective** (DTC agency; Snapchat-published Quay Sunglasses case, Nov–Dec 2025) — DPA campaigns: +40% ROAS vs non-dynamic, 2.86x CTR at 67% lower CPC, 131% lower cost per purchase; portfolio of 4 brands: $4M attributed revenue on ~$503K spend = 8.7x blended ROAS (range 3.6–12.8x) (T2, operator + platform-verified).
- **Measured** (incrementality vendor) — median incremental ROAS on Snapchat grew 104% between test periods (cited in Snap Q1 2026 earnings) (T2, third-party measurement).
- **Affinco** — small-budget benchmarks: CPM £2.50–4.00 (good/excellent under £2.50), swipe-up £0.10–0.30, swipe rate 0.8–1.2%, min daily spend $5.15; CPMs drop 15–25% off-peak; broad targeting beats narrow at small budgets (T3).
- **Funnelish** — CPI $1.50–4.00 for app installs; AR Lenses used 9B+ times/day, 75% of users engage daily (T3).
- **Snap developers docs** — AR Lens mechanics: second-price auction, billed on swipe; Lens/Filter placements (T1, platform docs).

## Beliefs
- **The edge is underpriced Gen Z/young-millennial CPMs + mature DPA tech** — "has a shelf life; once enough brands figure out the playbook, CPMs normalize" (CTC, OPINION/EMPIRICAL).
- **Most brands fail because they run Snap like a smaller Meta** — same creative, same bidding, same structure "almost never works"; Snap rewards native, product-forward content (CTC, CONSENSUS among operators).
- Warm-up matters: ramp pre-peak so the algorithm arrives with context; launching a new channel cold in November underperforms (CTC, HEURISTIC).
- Small budgets: broad targeting + auto-bidding (<£50/day) beats over-segmentation; over-segmenting = tiny budgets that can't optimize (Affinco, HEURISTIC).
- Attribution: 28-day click / 1-day view windows; view-through attribution inflates — focus click-through for small budgets (Affinco; platform docs).
- AR Lens: CPM-based, premium lenses cost £450k+/day; utility-driven effects + micro-influencers are the affordable path; lenses drive play-time/shares (brand metric), not direct response (Affinco/Snap docs).

## Failure modes
- Treating Snap as Meta-lite (repurposed creative) — the #1 failure (CTC).
- Testing with too-small budget and giving up before the algorithm learns (CTC).
- Cold-launching during peak season (no warm-up).
- Post-click neglect: slow/cluttered landing pages "convert or evaporate" the spend (Funnelish).
- Over-segmenting audiences with tiny budgets (Affinco).
- Expecting direct response from AR Lenses (brand format).

## Decision rules
1. IF DTC fashion/beauty/accessories/lifestyle targeting Gen Z THEN test Snap with DPAs + native creative before writing it off (CTC, EMPIRICAL, T2).
2. IF launching Snap THEN warm up 3–6 weeks pre-peak; never cold-launch in Q4 (CTC, HEURISTIC, T2).
3. IF budget < $50/day THEN use broad targeting + auto-bid, one format at a time (Affinco, HEURISTIC, T3).
4. IF running direct response THEN use Dynamic Catalog Ads + measure click-through conversions (28-day), not view-through (CTC/Affinco, HEURISTIC, T2).
5. IF buying AR Lenses THEN treat as brand/reach format (play time, shares, recall), budget from brand pool, not CPA pool (Snap docs/Affinco, FRAMEWORK, T2).
6. IF ROAS looks weak THEN check portfolio pattern first — CTC sees 3.6–12.8x range by vertical; sub-3x signals approach failure, not platform failure (CTC, EMPIRICAL, T2).
