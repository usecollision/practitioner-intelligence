# Panel — Microsoft Ads (Bing)

## Experts found
- **Melissa Mackey** (Head of Paid Search, Compound Growth Marketing; ex-JumpFly Director of Search Strategy; Bing Champion 2018/2019; Microsoft Ads Accredited Professional; PPC since 2002) — the canonical practitioner; verified via paidsearch.org profile, Search Engine Journal author page, and her Beyond the Paid columns (T1, fetched primary).
- **Lisa Raehsler** (Big Click Co) — the referenced post-import optimization guide (search partners, budgets, geo) (T2 via Mackey).
- **ROAS Expert / LSEO** — import mechanics + post-import adjustment tables (T3, agency content).

## Beliefs
- **"In general Bing outperforms Google, both in higher conversion rates and lower CPCs"** — not true for every client, but common (Mackey, EMPIRICAL/HEURISTIC, 2016 + long-running). Case: new client's cost per conversion on Bing was ¼ that of Google (Mackey, EMPIRICAL).
- **Bing users skew better-educated, higher household income** (Microsoft's Rik van der Kooi via Mackey) — different audience, not a clone (T2).
- **"Importing AdWords campaigns to Bing — many advertisers don't realize their job has just started with the import"** (Mackey, FRAMEWORK): imports are the starting point; bids, negatives, extensions, geo all need platform-native re-tuning (Mackey/Raehsler, CONSENSUS).
- **Bing "feels like a second language"**: ad-group-level targeting available (control PPCers like), targeting sometimes doesn't import cleanly, negative matching has fewer options (no negative broad match) (Mackey, EMPIRICAL).
- **Bing native/Microsoft Audience Network "isn't search"** — can't exclude sites or set per-site ads; adjust via bid modifiers (Mackey, HEURISTIC).
- Import frequency: re-import periodically to sync Google optimizations (LSEO, HEURISTIC).
- Automation is more manual in Microsoft Ads ("Manual mostly, some automatic") — plan for more hands-on management (LSEO, T3).

## Failure modes
- Import-and-forget: running Google settings that don't fit Bing's audience/mechanics (Mackey — the #1 mistake).
- Assuming identical match-type behavior; assuming same performance profile per keyword.
- Ignoring Audience Network placements (native) mixed into search results — treat separately.
- Copying Google bids directly without Bing-specific calibration (LSEO).
- Skipping Bing for clients with strong Google performance — leaves the higher-income/older demo and ¼-cost conversions on the table (Mackey).

## Decision rules
1. IF a Google Ads account exists THEN import to Microsoft Ads, then treat the import as a starting point: re-check bids, negatives (no negative broad), extensions, geo, and device targets (Mackey/Raehsler, FRAMEWORK, T1).
2. IF a client/account has older-skewing, higher-income, or Windows/Office/LinkedIn-adjacent ICP THEN prioritize Microsoft Ads — its audience differs from Google's (Mackey/Microsoft, EMPIRICAL, T2).
3. IF comparing platforms THEN compare cost-per-conversion and conversion rate, not CPC — Bing often wins both (Mackey, EMPIRICAL, T1).
4. IF running Microsoft Audience Network placements THEN manage with bid modifiers and separate performance expectations — native ≠ search (Mackey, HEURISTIC, T1).
5. IF a campaign underperforms on Bing but wins on Google THEN check match-type nuances and bid calibration before killing (LSEO/Mackey, HEURISTIC, T2).
6. IF re-optimizing Google THEN re-import to Microsoft Ads on a schedule to propagate improvements (LSEO, HEURISTIC, T3).
