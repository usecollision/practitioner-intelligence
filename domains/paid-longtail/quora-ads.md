# Panel — Quora Ads

## Experts found
- **Michal Pecánek** (Ahrefs, $200K+ Quora spend since 2017 across 3 global brands) — the primary practitioner source (T1, fetched full article).
- **GrowthSpree** (B2B SaaS) — intent-rich but small; measure on qualified pipeline (T2).
- **Quora for Business** — case studies: Asana (432K views paid+organic), Instapage (10% ad-click→trial conversion, 5x other social) (T2, platform-published).
- **Improvado** — mechanics guide citing Ahrefs numbers (T3).
- **Community thread** (quora.com, 2024) — "Hell no. They're so awful that... 'scraping the bottom of the barrel'" (T3, user sentiment — shows brand-recall problem in ad auction quality perception).

## Beliefs
- **Intent profile is real but narrow**: question-page context = consideration-stage intent; but volume is far below search; it is a complementary intent channel, never primary (Pecánek/GrowthSpree, CONSENSUS).
- **Cost advantage** (Pecánek, EMPIRICAL, 2023): 65% lower CPC than comparable Google search; 46% lower CPA; currently 40–50% cheaper CPC than Facebook, 60–95% cheaper than Google search; 2–6x MORE expensive than GDN but with better intent. "The days of super cheap clicks are long gone."
- **10–30% impression share is the cost-performance sweet spot** (Pecánek, EMPIRICAL/HEURISTIC).
- **Structure rules** (Pecánek): budget is campaign-level, bids ad-set-level; Quora's delivery favors higher bids → run ONE ad set per campaign; separate campaigns by country and device (group countries with similar CPCs).
- **Scaling is tiresome**: needs broader targeting (topic/interests, not just questions) to scale; questions retargeting deserves the spotlight (retarget question-viewers).
- Paid + organic (answers) combine — organic answers compound while ads capture; account managers can pull UI-missing data (Pecánek).
- Measure on qualified pipeline: "question-clickers vary in intent" (GrowthSpree, CONSENSUS).
- Platform's own docs emphasize contextual targeting + ABM (company targeting) (Quora Business, T2).

## Failure modes
- Judging on clicks/CTR without conversion pixel — "optimizing in the dark" (Improvado).
- Multiple ad sets per campaign with different bids — delivery skews to highest bid (Pecánek, EMPIRICAL).
- Expecting scale like Google — volume doesn't exist (all).
- Quality complaints in community: irrelevant/low-quality traffic perception (T3).
- Treating it as primary acquisition channel.

## Decision rules
1. IF B2B research-heavy category (comparison, "best X", how-to questions) THEN test Quora as a consideration-capture stream at 5–15% of search budget (Pecánek/GrowthSpree, HEURISTIC, T2).
2. IF running Quora THEN one ad set per campaign; separate campaigns per country/device (Pecánek, EMPIRICAL, T1).
3. IF optimizing delivery THEN target 10–30% impression share before scaling bids (Pecánek, EMPIRICAL, T1).
4. IF measuring THEN track cost per qualified lead/pipeline via CRM + pixel, never CTR alone (GrowthSpree/Improvado, HEURISTIC, T2).
5. IF a campaign lacks question volume for your niche THEN don't force it — Quora needs existing question activity (GrowthSpree, HEURISTIC, T2).
6. IF scaling beyond question targeting THEN broaden to topics/interests and retarget question-viewers (Pecánek, HEURISTIC, T1).
