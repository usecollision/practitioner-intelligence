# Panel — X (Twitter) Ads

## Experts found
- **Directive Consulting** (B2B paid media) — X's strongest B2B application is retargeting; first-party audience strategy + pipeline measurement (T2).
- **Upgrow** (X ads agency, 100+ tech brands) — claims 20–800% sales growth in first 90 days (T3, marketing claim; treat as directional).
- **Coinis** (ad-tech glossary, 2026) — mechanics: $20–50/day practical floor for Promoted Posts (below = patchy delivery); Trend/Timeline Takeover = 5–6 figure daily minimums, managed service; verticals: B2B SaaS, crypto, finance, live events strong; mass-market ecom better on Meta/TikTok (T3).
- **btaliat** (Affiliate World Forums) — publisher case: curiosity/emotional CTAs nearly doubled CTR on monetized tweets (T3, community intel).

## Beliefs
- X's real intent profile is weak at top of funnel: low-intent impressions unless you sequence — prospecting (video/image, familiarity) → retargeting (conversion objective: demos, gated content) (Directive, FRAMEWORK).
- Retargeting without replenishment loses efficiency fast; budget must balance prospecting feeding the retargeting layer (Directive, HEURISTIC).
- Brand safety objection on X is "fair but often outdated" — governed adjacency + first-party audiences turn it into an efficient revenue-influence layer (Directive, OPINION).
- Measure against pipeline, not platform metrics (Directive, FRAMEWORK).
- Self-serve floor ~$20–50/day; below that campaigns don't deliver — the #1 small-budget failure (Coinis, HEURISTIC, T3).
- Post-Musk advertiser base rebuilt 2024–25; pricing/inventory shifted; engagement-heavy metrics ≠ conversions (Coinis, T3).

## Failure modes
- Underfunded campaigns ($10–20/day) — patchy delivery, no learning.
- Prospecting without retargeting layer — budget erodes against low-intent impressions.
- Judging X on CTR/engagement (vanity) instead of pipeline.
- Mass-market ecom expecting Meta-like results — wrong audience profile.
- Repurposed LinkedIn-style B2B creative — X rewards conversational/native tone.

## Decision rules
1. IF B2B and budget < $50/day THEN don't start X as a prospecting channel; use it only as a governed retargeting layer fed by other channels (Directive, HEURISTIC, T2).
2. IF running X for conversions THEN sequence: familiarity campaign (video/image) → retargeting campaign with conversion objective (Directive, FRAMEWORK, T2).
3. IF measuring X THEN use pipeline (SQLs/demos) not CTR/engagement (Directive, FRAMEWORK, T2).
4. IF mass-market ecom THEN skip X; Meta/TikTok have the audience profile (Coinis, T3).
5. IF evaluating a takeover product THEN budget 5–6 figure daily minimums or don't (Coinis, T3).
